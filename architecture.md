# Shadowfax Architecture

## Overview

Shadowfax is a lightweight security monitoring platform designed to analyse
events generated by humans, AI agents and service accounts.

The platform consists of four main components:

```
           Event Sources
                 │
                 ▼
           FastAPI REST API
                 │
                 ▼
          SQLite Database
                 │
                 ▼
        Detection Engine
                 │
                 ▼
      Alerts & Risk Scoring
```

## Components

### app.py

Provides the REST API used to ingest events, retrieve alerts, update policy
settings and expose statistics.

### db.py

Handles all interaction with the SQLite database.

Stores:

- Events
- Alerts
- Policy

### detectors.py

Contains the detection engine.

Each detector evaluates an actor's activity and generates alerts when policy
rules are violated.

### seed_data.py

Contains bundled sample events and a default policy used during development.

### test_api.py

Integration tests that verify the API behaves correctly after changes.

## Detection Flow

1. Event received
2. Event stored in SQLite
3. Actor history loaded
4. Detection engine evaluates activity
5. Alerts written to database
6. Dashboard retrieves alerts through the API
